# Fast Skins MCP Server (`@fastskins/mcp`)

Official **Model Context Protocol (MCP)** server for **[Fast Skins (`fastskins.gg`)](https://fastskins.gg)** — the Brazilian Counter-Strike 2 skin price comparator that tracks Brazilian Pix marketplaces alongside global markets in real time.

> **[Versão em Português](https://fastskins.gg)** · **[English Version](https://fastskins.gg/en)** · **[Official API Docs](https://fastskins.gg/docs)**

---

## Why `@fastskins/mcp`?

- **Real-time BRL & Brazilian Pix stores:** compares DashSkins.com.br, DashSkins.gg, BRSkins, NeshaStore, BleikStore and dozens of global CS2 marketplaces in one call.
- **Zero dependencies & instant install:** runs directly via `npx -y @fastskins/mcp` (Node 18+) or Python `fastskins-mcp` (Python 3.10+). No API key required for public queries through the Fast Skins Edge Gateway.
- **Clean data rules out of the box:** filters stale >24h lines, validates Doppler / Gamma Doppler phases, flags Chinese-account-only markets (`Buff163` / `YouPin898`), and separates low-liquidity items.
- **Attribution included:** every response includes the verified timestamp and clickable canonical link to `https://fastskins.gg/skin/{slug}?utm_source=mcp`.

---

> Requires the Fast Skins Edge Gateway (`https://widget.fastskins.gg`) to be online.

## Tools

| Tool | Description |
|---|---|
| `comparar_preco_skin` | Returns best Brazilian Pix price, best global price, fresh marketplace count, 24h variation, other exteriors summary, timestamp and Fast Skins link. |
| `buscar_skins_cs2` | Searches CS2 skins by name, category (`rifles`, `pistolas`, `facas`, `luvas`, `smg`, `pesadas`) and maximum budget in BRL (`max_brl`). |
| `gerar_link_fastskins` | Builds canonical PT-BR or EN (`fastskins.gg/en`) links for any skin, exterior, StatTrak™, Souvenir or Doppler phase. |

## Installation

### Claude Desktop / Cursor / Windsurf / Antigravity (`npx`)

Add to your MCP configuration (`claude_desktop_config.json`, `.cursor/mcp.json`, or Antigravity MCP config):

```json
{
  "mcpServers": {
    "fastskins": {
      "command": "npx",
      "args": ["-y", "@fastskins/mcp"]
    }
  }
}
```

### Remote (no install) — ChatGPT, Claude and any Streamable HTTP client

```
https://widget.fastskins.gg/mcp
```

No authentication. In ChatGPT: Plugins → + → *Add custom MCP server*.

### Python (`pip` / `uvx`)

```bash
pip install fastskins-mcp
# or run directly:
python -m fastskins_mcp
```
